# Skill: Plan Issues

## Purpose
Read all open issues, resolve blocking relationships into a DAG, group them
into sequential phases where each phase contains every unblocked issue
(no cap on parallelism), and produce two outputs:
1. `issues/EXECUTION_PLAN.md` — human-readable plan with Mermaid diagram
2. `scripts/worktree-run.sh` — generated script with phase arrays populated

## Instructions

### 1. Read all open issues
For each file in `issues/open/` extract: issue number, title, blocked-by
list, branch name (from ## Git section), type (AFK or Human-in-loop).

### 2. Build the DAG
Node = issue. Edge A → B = B must complete before A. Flag circular deps.

### 3. Topological sort into phases
- Phase 1: no blockers
- Phase 2: blockers all in Phase 1
- Phase N: blockers all in earlier phases
No cap — all unblocked issues in a phase run simultaneously as worktrees.

### 4. Flag Human-in-loop issues
Exclude from worktree-run.sh. List separately with the phase they depend on.

### 5. Write EXECUTION_PLAN.md
Include:
- Summary (total issues, phases, peak parallel worktrees)
- Mermaid `graph TD` diagram with classDef colour-coding per phase
- One section per phase: issue table + run command
- Human-in-loop section
- Merge order summary
- Conflict risk table (issues in same phase touching same files)

### 6. Write scripts/worktree-run.sh
Populate all PHASE_N_ISSUES arrays with actual slugs ("NNN-slug" format).
Use the template below exactly.

## EXECUTION_PLAN.md Template

```markdown

**Phases:** [N]

```

## worktree-run.sh template

```bash
#!/usr/bin/env bash
# worktree-run.sh — run all issues in a phase as parallel worktrees
# GENERATED by /plan-issues — do not edit phase arrays manually
# Usage: ./scripts/worktree-run.sh [phase-number]

# NOTE: No set -e — errors handled explicitly so subshells do not die silently

PHASE="${1}"
WORKTREE_BASE="$(pwd)/.worktrees"
APP_ROOT="$(pwd)"

if [ -z "$PHASE" ]; then
  echo "Usage: ./scripts/worktree-run.sh [phase-number]"
  exit 1
fi

PHASE_1_ISSUES=([GENERATED: "001-slug" "002-slug"])
PHASE_2_ISSUES=([GENERATED: "003-slug"])

PHASE_VAR="PHASE_${PHASE}_ISSUES[@]"
ISSUES=("${!PHASE_VAR}")

if [ ${#ISSUES[@]} -eq 0 ]; then
  echo "No issues for Phase $PHASE."
  exit 1
fi

echo "Parallel worktrees: ${#ISSUES[@]}"
git checkout main && git pull
mkdir -p "$WORKTREE_BASE"

PIDS=()
SLUGS=()

for ISSUE_SLUG in "${ISSUES[@]}"; do
  NNN="${ISSUE_SLUG%%-*}"
  BRANCH="feature/${ISSUE_SLUG}"
  WORKTREE_PATH="${WORKTREE_BASE}/${ISSUE_SLUG}"

  [ -d "$WORKTREE_PATH" ] && {
    git worktree remove "$WORKTREE_PATH" --force 2>/dev/null || true
    git branch -D "$BRANCH" 2>/dev/null || true
  }

  git worktree add "$WORKTREE_PATH" -b "$BRANCH" main

  ISSUE_FILE=$(ls "$APP_ROOT"/issues/open/${NNN}-*.md | head -1)
  ISSUE_CONTENT=$(cat "$ISSUE_FILE")
  EPICS=$(cat "$APP_ROOT"/issues/epics/*.md 2>/dev/null || echo "")
  FEATURES=$(find "$APP_ROOT/issues/features" -name "*.md" | xargs cat 2>/dev/null || echo "")
  IMPLEMENT_PROMPT=$(awk '/^---/{i++} i>=2{print} i<2 && /^---/{next}' \
    "$APP_ROOT/.claude/skills/implement/SKILL.md" 2>/dev/null || echo "skill not found")
  AUDIT_PROMPT=$(awk '/^---/{i++} i>=2{print} i<2 && /^---/{next}' \
    "$APP_ROOT/.claude/skills/audit/SKILL.md" 2>/dev/null || echo "skill not found")
  SPEC_DOCS=$(cat "$APP_ROOT"/docs/*.md 2>/dev/null || echo "no spec docs")
  LOG_FILE="${WORKTREE_BASE}/${ISSUE_SLUG}.log"
  AUDIT_LOG="${WORKTREE_BASE}/${ISSUE_SLUG}.audit.log"

  (
    cd "$WORKTREE_PATH"
    FULL_PROMPT="$IMPLEMENT_PROMPT

---
EPICS:
$EPICS

---
FEATURES:
$FEATURES

---
ISSUES:
$ISSUE_CONTENT"

    OUTPUT=$(echo "$FULL_PROMPT" | claude --permission-mode acceptEdits -p 2>&1)
    echo "$OUTPUT" > "$LOG_FILE"

    echo "$OUTPUT" | grep -q "\[BLOCKED" && exit 2

    DIFF=$(git diff main...HEAD)
    [ -z "$DIFF" ] && exit 3

    AUDIT_FULL_PROMPT="$AUDIT_PROMPT

---
ISSUE:
$ISSUE_CONTENT

---
SPEC_DOCS:
$SPEC_DOCS

---
DIFF:
$DIFF"

    AUDIT=$(echo "$AUDIT_FULL_PROMPT" | claude -p)
    echo "$AUDIT" > "$AUDIT_LOG"

    echo "$AUDIT" | grep -q "\[APPROVED\]" || exit 1

    git push -u origin "$BRANCH"
    exit 0
  ) &
  PIDS+=($!)
  SLUGS+=("$ISSUE_SLUG")
done

APPROVED=(); FAILED=(); BLOCKED=(); ERROR=()
for i in "${!PIDS[@]}"; do
  wait "${PIDS[$i]}"; CODE=$?
  case $CODE in
    0) APPROVED+=("${SLUGS[$i]}") ;;
    1) FAILED+=("${SLUGS[$i]}") ;;
    2) BLOCKED+=("${SLUGS[$i]}") ;;
    *) ERROR+=("${SLUGS[$i]}") ;;
  esac
done

echo "✓ APPROVED + pushed: ${#APPROVED[@]} — open PRs on GitHub"
[ ${#FAILED[@]} -gt 0 ] && echo "✗ AUDIT FAILED: ${#FAILED[@]}"
[ ${#BLOCKED[@]} -gt 0 ] && echo "⚠ BLOCKED: ${#BLOCKED[@]}"
echo ""
echo "Next: open PRs → review → merge → ./scripts/worktree-merge.sh $PHASE"
```

## Output summary
List: phases, issues per phase, peak parallel count, Human-in-loop issues,
circular dependencies, conflict risks, and the start command.
