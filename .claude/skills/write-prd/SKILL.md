# Skill: Write PRD

## Instructions
1. Do not ask further questions unless critically ambiguous.
2. Write the PRD using the template below.
3. Save to `issues/prd-[feature-name].md`.
4. List the modules this feature will touch.
5. Ask: "Does this module list look right? Confirm to proceed."

## PRD Template

# PRD: [Feature Name]
## Problem
## Solution
## User Stories
## Acceptance Criteria
## Data Model
## Module Map
## Implementation Decisions
## Out of Scope
## Testing Strategy
